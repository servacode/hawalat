## المرحلة 0 — الأساسات (Foundations)

- **الحالة:** ✅ **مقبولة ومغلقة** — 2026-08-07
- **الهدف المعلن:** بيئة تعمل بأمر واحد: Django + Next.js + Docker + CI + أدوات جودة.

### ما أُنجز
- Backend: Django 5.1 + DRF + Channels + Celery، إعدادات مقسّمة (base/dev/prod)، تطبيق `core`، نقطة `/api/health/`، اختبار دخاني.
- Frontend: Next.js 15 + TS + Tailwind 4، عربي/RTL، خط Tajawal، نواة طبقة التوكِنز بألوان الهوية.
- بنية: docker-compose (db+redis+web+worker+frontend)، Dockerfiles، Makefile، pre-commit، GitHub Actions CI، `.env.example` يخدم الوضعين.

### فحص القبول

| القاعدة | النتيجة | الدليل |
|---|---|---|
| ق1 المركزية | ✅ | الألوان في `globals.css` كطبقة توكِنز (`--brand-600`، `--accent`...) والصفحة التمهيدية تستهلك `bg-brand`/`text-muted` فقط — لا hex يدوي في أي مكوّن. الخط عبر متغيّر `--font-tajawal` |
| ق2 العزل | ➖ لا ينطبق بعد | لا نماذج بيانات مالية في هذه المرحلة — يبدأ فرضه في المرحلة 1 (`TenantScopedModel`) |
| ق3 المحاسبة | ➖ لا ينطبق بعد | محرك القيود يبدأ في المرحلة 1/4 |
| ق4 RBAC | ➖ لا ينطبق بعد | DRF مضبوط افتراضياً على `IsAuthenticated` (أساس آمن)، التفصيل في المرحلة 2 |
| ق5 RTL | ✅ | `<html lang="ar" dir="rtl">` من الجذر + `font-feature-settings: "tnum"` للأرقام |
| ق6 فاتح/داكن | ✅ | التوكِنز معرّفة للوضعين عبر `prefers-color-scheme` في نفس الطبقة |
| ق7 الاختبارات | ✅ | اختبار دخاني لنقطة الصحة يمرّ (`manage.py test` → OK) |
| ق8 الجودة | ✅ | `ruff check` + `ruff format --check` نظيفان، `npm run lint` نظيف، CI مُعدّ للطرفين |
| ق9 التشغيل | ✅ | `docker compose config` سليم؛ محلياً بلا Docker: sqlite تلقائي والاختبارات تمرّ. **ملاحظة:** تشغيل compose الفعلي غير ممكن في بيئة العمل السحابية (لا daemon) — **يُتحقق منه على جهاز المالك** |
| ق10 التوثيق | ✅ | قسم "التشغيل" في README + هذا السجل |

### ملاحظات وديون مؤجلة
1. **تشغيل `docker compose up` الفعلي** لم يُختبر إلا بنيوياً (لا Docker daemon في بيئة العمل) — يُجرَّب على جهاز المالك أول مرة.
2. طبقة التوكِنز الحالية **نواة مختصرة** — التوسعة الكاملة (كل تدرّجات الهوية والمقاييس والظلال) هي صلب المرحلة 1.
3. الصفحة الرئيسية placeholder مؤقت — تُستبدل ببوابة الدخول في المرحلة 2.
4. لا يوجد PR بعد: المستودع بلا فرع أساسي (`main`) للمقارنة — يُفتح PR عند إنشائه.

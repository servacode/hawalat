# مشروع حوالات — النشر التجريبي المجاني على Render (Free Hosting)

> الهدف: نسخة حيّة **مجانية** للتجربة واكتشاف الأخطاء قبل النشر الحقيقي.
> كل شيء مُجهّز في `render.yaml` — يتبقى عليك 5 دقائق من النقرات.

---

## الخطوات (مرة واحدة)

### 1. أنشئ حساب Render
- اذهب إلى **render.com** واضغط **Get Started** وسجّل بحساب GitHub نفسه الذي فيه هذا المستودع (الأسهل).

### 2. انشر بالـ Blueprint
1. من لوحة Render: **New ← Blueprint**.
2. اختر مستودع `hawalat` (امنح Render صلاحية الوصول إن طُلبت).
3. سيقرأ `render.yaml` ويعرض الخدمات الأربع: قاعدة + Redis + API + واجهة.
4. سيسألك عن **BOOTSTRAP_ADMIN_PASSWORD** → ضع كلمة مرور الأدمن (8+ أحرف، غير شائعة، فيها حروف).
5. اضغط **Apply** وانتظر (أول بناء 5–10 دقائق ☕).

### 3. افتح المنصة
- الواجهة: `https://hawalat-app-demo.onrender.com`
- سجّل دخول الأدمن: `admin` + كلمة المرور التي وضعتها.

> **إن كانت الأسماء محجوزة** وأضاف Render لاحقة (مثل `hawalat-api-demo-x3kf`):
> افتح إعدادات كل خدمة ← Environment وحدّث المتغيرات الموسومة (†) في
> `render.yaml` بالروابط الفعلية، ثم **Manual Deploy** للواجهة والـAPI.

## جولة التجربة المقترحة (Smoke Test)

بنفس ترتيب الدورة التشغيلية:

1. **أدمن** → المكاتب الكبيرة → فتح مكتب كبير (مثلاً: `مكتب دمشق` / `damascus`).
2. خروج → دخول **المكتب الكبير**:
   - الصناديق ← العملات: أضف `USD` و`TRY`.
   - الصناديق ← صندوق وسيط: «الوعد #101» بالعملتين.
   - الحسابات ← مكتب صغير جديد (مثلاً `aleppo`) + حدّه السالب بالدولار.
   - صندوق الوعد ← **اعتماد** 2000 USD باسم حلب.
3. خروج → دخول **المكتب الصغير**:
   - إرسال حركة (1000 USD → دمشق) → لاحظ نص الواتساب.
4. ارجع للكبير (متصفح آخر أجمل — سترى **اللحظي** يعمل):
   - الحركات الجارية → معالجة → الوعد + أجور 10/15 → قبول.
   - السجل → مدفوعة → تم التسليم.
5. تحقق: صناديق الطرفين، **مطابقة** حلب، **تقرير الأرباح** (يجب أن يُظهر 5) وتصدير PDF.

سجّل أي خطأ/ملاحظة تراها — نصلحها فوراً.

## حدود الخطة المجانية (مقبولة للتجربة)

| الحد | الأثر |
|---|---|
| الخدمات تنام بعد ~15 دقيقة خمول | أول طلب بعد النوم يتأخر ~50 ثانية (طبيعي) |
| قاعدة البيانات المجانية مؤقتة | تنتهي بعد فترة وفق سياسة Render — **للتجربة فقط، لا بيانات حقيقية** |
| Redis مجاني بلا حفظ دائم | إعادة تشغيله تفقد الطابور المؤقت — غير مؤثر بالتجربة |
| بلا Shell | لذلك الأدمن يُنشأ تلقائياً عبر `bootstrapadmin` |
| بوت الواتساب | يحتاج بوابة خارجية — جرّب **الوضع اليدوي بالرابط** (يعمل كاملاً) |

> للنشر الحقيقي لاحقاً: `docs/06-deployment.md` (خادمك الخاص، بيانات دائمة، بوت كامل).

## استكشاف أخطاء التجربة

| العرض | الحل |
|---|---|
| البناء فشل في `keyvalue` | حساب قديم؟ بدّل في render.yaml إلى `type: redis` |
| الواجهة تفتح لكن الدخول يفشل | تحقق من متغيرات (†) — الـAPI URL صحيح؟ ثم أعد نشر الواجهة |
| «CORS» في كونسول المتصفح | حدّث `CORS_ALLOWED_ORIGINS` برابط الواجهة الفعلي وأعد نشر الـAPI |
| الجرس لا يتحدث لحظياً | تحقق `NEXT_PUBLIC_WS_URL` يبدأ بـ `wss://` وبرابط الـAPI الصحيح |
| 400 على كل طلبات الـAPI | `DJANGO_ALLOWED_HOSTS` لا يطابق رابط الـAPI الفعلي |

# 💸 حوالات — نظام محاسبي لإدارة الحوالات

> منصة **SaaS متعددة المستأجرين** لإدارة الحوالات المالية بين المكاتب، جوهرها **أداة محاسبية**
> تجعل كل مكتب يعرف **ما له وما عليه** بوضوح تام — كل دفع أو اعتماد يُسجَّل ويظهر في السجلات المالية.

**الحالة:** 🟡 مرحلة التخطيط والتوثيق مكتملة — جاهز لبدء البناء.

</div>

---

## 📌 الفكرة

نظام يربط ثلاثة مستويات من المستخدمين في منصة واحدة، بواجهة دخول موحّدة وصلاحيات حسب الدور:

| الدور | المهمة | العلاقة المالية |
|---|---|---|
| 👑 **الأدمن** (صاحب المنصة) | يدير المكاتب الكبيرة والباقات والاشتراكات | ❌ إداري بحت — لا يرى أي مال |
| 🏢 **المكتب الكبير** (مستأجر معزول) | يستقبل الحركات، يعالجها، يدير الصناديق والأرصدة | ✅ محور المحاسبة |
| 🧾 **المكتب الصغير** (تابع) | يُنشئ الحركات ويتابع حسابه محاسبياً | ✅ يرسل ويتابع فقط |

كل **مكتب كبير = مستأجر مستقل** ببيانات معزولة تماماً. المكاتب الصغيرة تابعة له، تُرسل حوالاتها عبره.

## ✨ أبرز الميزات

- 🔄 **دورة حركة كاملة:** إرسال → قيد الانتظار → قبول/رفض، مع حالات مستقلة للدفع والتسليم.
- 🧮 **محرك قيود مزدوجة:** كل عملية تولّد قيوداً متوازنة تلقائياً (لا حذف — عكس قيد فقط).
- 💱 **حوالات ثنائية العملة** مع سعر صرف مثبّت بتاريخ الحركة.
- 📦 **صناديق:** صناديق المحل (النقد الفعلي) + صناديق الوسطاء (اعتماد/سحب/كشف).
- 📊 **الأرباح** (فرق الأجور) + **13 تقريراً** مع تصدير PDF/Excel.
- 🔐 **حدود سالبة** لكل عملة تمنع الإرسال عند تجاوزها.
- 📄 **كشوف حسابات ومطابقة** دورية قابلة للإرسال عبر واتساب.
- 🟢 **تكامل واتساب** (رابط افتراضياً + بوت اختياري).
- ⚡ **تحديث لحظي** (WebSockets) للحركات والأرصدة والإشعارات.
- 📢 **إشعارات آلية** (جرس + إشارة) و**تنبيهات بشرية** (بث).
- 💳 **باقات واشتراكات** (حد المكاتب + الحركات) مع وضع مجاني قابل للتبديل.
- 📱 **ويب أولاً** قابل للتثبيت كتطبيق (PWA).

## 🛠️ الحزمة التقنية

| الطبقة | التقنية |
|---|---|
| Backend | **Django + DRF** · PostgreSQL · Celery |
| الوقت الحقيقي | **Django Channels + WebSockets + Redis** |
| Frontend | **Next.js (React) + TypeScript** · TanStack Query |
| التصميم | **Tailwind + توكِنز مركزية** (RTL أولاً، فاتح/داكن) |
| المصادقة | JWT مع صلاحيات حسب الدور (RBAC) + عزل مستأجرين |
| التصدير | WeasyPrint/ReportLab (PDF) · openpyxl (Excel) |

**قرارات معمارية:** قاعدة واحدة + `tenant_id` (عزل صارم) · عربي أولاً (بنية i18n) · لا حذف (عكس قيد) · نظام مركزي كامل من البداية.

## 🚀 التشغيل (بيئة التطوير)

```bash
# 1) انسخ متغيرات البيئة
cp .env.example .env

# 2) شغّل كل شيء بأمر واحد (PostgreSQL + Redis + Backend + Worker + Frontend)
docker compose up --build
```

- الواجهة: http://localhost:3000 · الـ API: http://localhost:8000 · فحص الصحة: `/api/health/`

**بلا Docker** (تطوير سريع — يستخدم sqlite تلقائياً):

```bash
# Backend
cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements/dev.txt
.venv/bin/python manage.py migrate && .venv/bin/python manage.py runserver

# Frontend
cd frontend && npm install && npm run dev
```
